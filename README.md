# FastCheck
A Bash Script to check for Persistant Threats using RKHunter and CHKRootkit

Compatible With: Linux -> Debian/Ubuntu, Red-Hat/Fedora and Arch based distros

Steps to Use:
1. Click <a href="https://github.com/Adock90/FastCheck/releases/tag/FastCheck">Releases</a> and download
2. Verify with <code>sha256sum FastCheck.sh</code>
   Output in sha256sums.txt

3. Call with <code>sudo FastCheck.sh</code>
4. Enjoy

Note this is not an perfect solution
