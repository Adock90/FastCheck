# FastCheck
A Bash Script to check for Persistant Threats using RKHunter and CHKRootkit

Compatible With: Linux -> Debian/Ubuntu, Red-Hat/Fedora and Arch based distros

## Steps to Use:

# 1. Click <a href="https://github.com/Adock90/FastCheck/releases/tag/FastCheck1.1.1">Releases</a> and <a href="https://github.com/Adock90/FastCheck/releases/download/FastCheck1.1.1/FastCheck.sh">download</a>

# 2. Verify with: Output in sha256sums.txt

   <code>sha256sum FastCheck.sh</code>

# 4. Call with <code>sudo FastCheck.sh</code>

# 5. Enjoy
